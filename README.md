# PewTube
This is a quick and painless downloader for YT and FB videos, as well as many other web video sources. It uses YT-DLP and FFMPEG to do all the heavy lifting in a simple Windows-friendly GUI. Currently only for single video URLs. I may or may not upgrade it in the future to batch process multiple videos. If it's not there by the time you read this, I will be upgrading the download options to allow audio only.
